Clark Video Archiver

Setup and usage.

  1. Save a video

    Right-click any video → “Save this video to disk”. That is the main path, and on most sites it is all you need.

  2. If the right-click menu has no video option

    Many players stack an invisible layer over the video, so the browser never registers that you right-clicked one. Use right-click → Clark Video Archiver → Save video on this page instead.

  3. Otherwise use the toolbar button

    It lists every media file seen in the tab, including streams caught on the network that never appear in the page itself. The number on the icon is how many were found.

    Press play first. Most players request nothing until playback starts, so a page checked before you press play often looks empty. Play the video, then press Rescan.

  4. Streaming video says “Build video”

    A stream is not one file — it is hundreds of small segments listed in a playlist. Build video opens a page that downloads every segment and joins them back together. Choose a quality if asked, then leave that tab open until it finishes.

  5. Subtitles

    Tick Also save subtitles in the toolbar popup and any subtitle track the stream offers is saved beside the video as a .vtt file, named to match so players pick it up automatically.

    Only streams that actually publish a subtitle track have one to save; you are told when there is none rather than left guessing.

  6. Where files go

    Downloads/ClarkVideoArchiver/, named after the page title. Tick Ask where to save each file in the toolbar popup to choose a location each time instead.

Optional. Everything on the first tab works without this. Set it up only if you want MP4 instead of .ts files, or want awkward sites handled by yt-dlp.

Two things are impossible inside a browser page: converting MPEG-TS streams to MP4, and joining separate audio and video tracks. Both need a real media toolchain, so the extension can hand those jobs to a small program you run yourself. Nothing is sent anywhere else.

  1. Install ffmpeg, and yt-dlp if you want it

    ffmpeg is required. yt-dlp is needed only for page URLs rather than direct video links. Linux or macOS, with Python 3.9 or newer.

    sudo apt install ffmpeg && pip install yt-dlp
    brew install ffmpeg yt-dlp

  2. Start the helper

    Run this from the folder holding the extension source:

    ./server/cva_helper.py

    It prints the address it is listening on, then keeps running. Leave that terminal open while you use it.

  3. Connect it below

    Tick Enable, leave the endpoint alone unless you changed the port, then press Test connection.

  4. Use it

    A Helper button now appears beside each video in the toolbar popup. It opens a progress page that submits the job, waits for the service, and saves the finished file.

No video option when right-clicking The site has a layer over the video. Use Clark Video Archiver → Save video on this page, or the toolbar button.
Nothing found on any site (Firefox) Site access is normally granted automatically. If nothing is found anywhere, open about:addons, select this extension, and check Permissions and data → Access your data for all websites.
I got a .ts file, not .mp4 The stream used MPEG-TS segments. That file is valid and plays in VLC or mpv. For an MP4, either set up the helper service, or convert it: ffmpeg -i in.ts -c copy out.mp4
The video has no sound That stream carries audio as a separate track. Save the audio entry from the popup too, then join them: ffmpeg -i video.mp4 -i audio.mp4 -c copy out.mp4
No subtitles were saved Only streams publishing a subtitle track have one to save. Burned-in captions are part of the picture and cannot be extracted. If the build page said the stream lists no subtitle track, there was nothing to fetch.
Netflix, Disney+ and similar do not work Those use DRM. The decrypted video never exists anywhere an extension can reach, so no extension can save them. This cannot be fixed.
Test connection fails Check the helper terminal is still running and the port matches what it printed. If you started it with --token, the same token must be entered here.
A download stopped partway Closing the build tab cancels it. Leave that tab open until it reports Saved.
